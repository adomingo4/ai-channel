Optional background music.

Put one or more music files here (.mp3, .m4a or .wav) and every video gets one of them,
played quietly under your voice. It dips automatically whenever you speak.

Use only music you are allowed to use on monetised YouTube videos, for example:
- YouTube Audio Library: YouTube Studio > Audio Library (free, made for YouTube)
- Pixabay Music: pixabay.com/music (free, no attribution needed)

Calm, instrumental tracks with no singing work best. Leave this folder empty for no music.
